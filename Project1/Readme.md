# This is Project 1 of COSC 320.
## Contents

1. **2DRegressionGraph.png** : Resulting linear regression of the points in the file points100.dat
2. **COSC320 Project1 README.pdf** : This is the required ReadMe file that contains info on the project.
3. **Readme.md** : This file.
4. **Regression Complexity.PNG** : This is a graph made from the time complexity of the regression from larger amount of data points.
5. **Sampleoutput.png** : A sample output image from running the program with different points.dat files.
6. **Sampleoutput2.png** : Another sample output image.
7. **main.cpp** : The main that runs the different matricies functions (Inverse, Transpose, Multiplication, Subtraction).
8. **main2.cpp** : The main that tests the linear regression functions.
9. **makefile** : The makefile that compiles the programs for the project.
10. **matrix.cpp** : A C++ file that contains the definition of the matrix Class.
11. **matrix.h** : A C++ header files that contains the declaration of the matrix Class.
12. **points100-3d.dat** : Contains the data points for the 3-dimensional linear regression.
13. **points100.dat** : Contains the data points for the 2-dimensional linear regression.

* Notes:
  - This project does not regress data points greater than three dimensions.
