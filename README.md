# COSC320-001 At Salisbury University.

## It Contains:

- All labs 01 - 11
- All three projects

### Lab/Project Content:
* Lab 01: Bubble, Insertion, And Selection Sort Runtime Complexity Comparisons.
* Lab 02: Merge And Quick Sort Runtime Complexity Comparisons.
* Lab 03: Heap Sort Runtime Complexity Analysis.
* Lab 04: Runtime Complexity Analysis On Heap Functions.
* Lab 05: Time Complexity Comparison For Matrix Multiplication And Addition.
* Lab 06: Runtime Complexity For Quick Sort, Random Quick Sort, Merge Sort, Heap Sort, And Testing The Hiring Problem.
* Lab 07: Create Your Own Hash Value And Testing Collisions.
* Lab 08: In this lab, it contains a user-interface for a Binary Tree with a hand full of functions (such as Insert, Delete, find Successor) and an optional Binary Tree runtime testing rig.
* Lab 09: In this lab, I created a program that was meant to compare the runtime of different functions for a Red-Black Tree and a regular Binary Tree. It contains both a user-interface for the Red Black Tree, and testing method to compare runtimes.
* Lab 10: This lab is meant to programmically create a method to traverse a graph using Breadth First Search (BFS) along with multiple other features.
* Lab 11: Similar to lab 10, this lab creates a graph (both directed & undirected) through a file input, then it performs a Breadth First Search, a topogical sort, a reversal of the graph, (if directed) then re-runs BFS in order to discover if the graph contains any strongly connected components.
